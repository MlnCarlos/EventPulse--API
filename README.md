# EventPulse REST API

API REST desarrollada con Java 17 y Spring Boot para la gestión de eventos, aplicando buenas prácticas de diseño, arquitectura por capas (Controller-Service-DTO-Model) y control de respuestas HTTP.

## Requisitos de Entorno
* Java Development Kit (JDK) 17 o superior
* Maven (incluido mediante `./mvnw` o `mvnw.cmd`)

## Instrucciones de Ejecución

1. Abrir la terminal en la raíz del proyecto.
2. Ejecutar el comando:
   ```bash
   ./mvnw spring-boot:run
